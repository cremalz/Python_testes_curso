# 🐍 Meus Estudos de Python

Repositório com exercícios práticos das minhas aulas de Python. Cada arquivo representa um conceito ou desafio trabalhado durante o aprendizado.

---

## 📁 Estrutura dos Projetos

### 🟢 Introdução — Entrada e Saída de Dados

| Arquivo | Descrição |
|---|---|
| `prazer.py` | Primeiro contato com `input()` e `print()` — pede o nome do usuário e exibe uma saudação |
| `idade_nome_peso.py` | Coleta nome, idade e peso; depois data de nascimento — prática de múltiplos `input()` |
| `Nomecompleto.py` | Analisa um nome completo: maiúsculas, minúsculas, contagem de letras e tamanho do primeiro nome |

---

### 🔢 Matemática e Cálculos

| Arquivo | Descrição |
|---|---|
| `testes_de_calculos_simples.py` | Recebe dois números e exibe soma, subtração, multiplicação e divisão |
| `tabuada.py` | Gera a tabuada completa (de 1 a 10) de qualquer número escolhido pelo usuário |
| `math.py` | Uso da biblioteca `math` para calcular raiz quadrada e arredondamento (`ceil`/`floor`) |
| `analize_de_numero.py` | Decompõe um número de 4 dígitos em unidade, dezena, centena e milhar |
| `calculadorafinanceira.py` | Calculadora de metas financeiras: calcula em quantos meses o usuário atingirá seu objetivo com base na renda e gastos mensais |

---

### 📝 Manipulação de Strings

| Arquivo | Descrição |
|---|---|
| `fraseA.py` | Conta quantas vezes a letra **A** aparece em uma frase, e localiza a primeira e última ocorrência |
| `expecificavetores.py` | Analisa uma string com métodos como `isspace()`, `isnumeric()`, `isalpha()`, `isupper()`, `islower()` e `istitle()` |
| `cidade_santo.py` | Verifica se o nome de uma cidade começa com "Santo" usando fatiamento de string |

---

### 🎲 Aleatoriedade e Listas

| Arquivo | Descrição |
|---|---|
| `ramdom.py` | Gera um número aleatório entre 1 e 10 com `random.randint()` |
| `Sorteio.py` | Sorteia aleatoriamente um aluno entre quatro nomes informados com `random.choice()` |
| `escolhaemordem.py` | Embaralha a ordem de apresentação de quatro alunos com `random.shuffle()` |

---

### 🎮 Jogos e Projetos

| Arquivo | Descrição |
|---|---|
| `pedra_papel_tesoura.py` | Jogo de Pedra, Papel e Tesoura contra o computador com emojis e lógica de vitória/derrota |
| `import_pygame.py` | Jogo básico com **Pygame** — quadrado vermelho controlado pelas setas do teclado numa janela 800x600 |
| `musica_em_python.py` | Reprodução de arquivo de áudio (`jesus.mp3`) usando `pygame.mixer` |

---

## 🧰 Bibliotecas Utilizadas

- `math` — funções matemáticas (raiz quadrada, arredondamento)
- `random` — geração de números aleatórios e embaralhamento
- `pygame` — criação de jogos e reprodução de áudio

---

## 📈 Conceitos Aprendidos

- ✅ Entrada e saída de dados com `input()` e `print()`
- ✅ Variáveis e tipos primitivos (`int`, `float`, `str`)
- ✅ Operações aritméticas
- ✅ Formatação de strings com `.format()`
- ✅ Métodos de string (`.upper()`, `.lower()`, `.strip()`, `.count()`, `.find()`, `.rfind()`, etc.)
- ✅ Fatiamento de strings
- ✅ Listas e manipulação com `random`
- ✅ Estruturas condicionais (`if`, `elif`, `else`)
- ✅ Laços de repetição (`while`)
- ✅ Importação e uso de bibliotecas externas
- ✅ Primeiros passos com **Pygame** (janela, eventos, teclado, áudio)

---

## 🚀 Como executar

Certifique-se de ter o **Python 3** instalado. Para os arquivos que usam Pygame:

```bash
pip install pygame
```

Depois, execute qualquer arquivo com:

```bash
python nome_do_arquivo.py
```
